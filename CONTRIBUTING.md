# Contributing

This release candidate is unpublished. No public issue tracker is available yet. Keep changes small and use Python's standard library only. Run `python3 -m unittest discover -s tests -v` locally with tar and zstd installed. Use temporary data and local bare Git remotes. Never use production machines or private storage in tests.
